# Sumit Verma - Portfolio

A modern, responsive portfolio website built with React, showcasing my skills and projects as a Full-Stack & Backend Developer.

## Features

- Responsive design that works on all devices
- Smooth animations using Framer Motion
- Parallax effects with Simple Parallax JS
- Interactive sliders with Swiper.js
- Scroll animations with AOS (Animate On Scroll)
- Modern UI components and layout
- Contact form with validation
- Showcase of projects including PresenceIQ and Hospital Management System

## Technologies Used

- **React** - JavaScript library for building user interfaces
- **Framer Motion** - Animation library for React
- **AOS** - Animate On Scroll library
- **Swiper.js** - Modern mobile touch slider
- **Simple Parallax JS** - Parallax scrolling effect
- **GSAP** - GreenSock Animation Platform
- **Django** - Backend framework for PresenceIQ project
- **Node.js/Express** - Backend for Hospital Management System
- **MongoDB/MySQL** - Database systems
- **OpenCV** - Computer vision library for AI projects

## Libraries Integrated

1. **Framer Motion** - For smooth, spring-based animations
2. **AOS (Animate On Scroll)** - For scroll-triggered animations
3. **Swiper.js** - For interactive sliders in the skills section
4. **Simple Parallax JS** - For parallax effects on images
5. **GSAP** - For advanced animations (planned for future enhancements)

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm start
   ```

4. Build for production:
   ```
   npm run build
   ```

## Deployment

This portfolio can be deployed to various platforms:
